Nesta formação de Node.js, exploramos tópicos cruciais para o desenvolvimento robusto de aplicações back-end, do zero até o deploy. O objetivo é aprofundar os conhecimentos em testes, abordando desde os fundamentos de testes unitários até os testes end-to-end.

São usadas tecnologias como Fastify, NestJS e conceitos fundamentais como SOLID e DDD. Explorando padrões de design, como o Factory Patter e o Repository Pattern, para estruturar o código de maneira eficiente.

## Nível I

**Fundamentos do Node.js**

Nesse primeiro módulo desenvolvemos uma API RESTful com Node.js focada nos fundamentos da tecnologia, sem frameworks ou bibliotecas externas. Aprenderemos sobre módulos internos do Node.js, especialmente HTTP e Streams, e sobre fundamentos HTTP como Requests, Responses, Headers, status code e os diferentes tipos de parâmetros.
