In this Node.js training, we explore crucial topics for the robust development of back-end applications, from scratch to deployment. The goal is to deepen knowledge in testing, covering everything from the fundamentals of unit tests to end-to-end tests.

Technologies such as Fastify and NestJS are used, along with fundamental concepts like SOLID and DDD. Exploring design patterns, such as the Factory Pattern and Repository Pattern, to structure the code efficiently.

## Level I

**Node.js Fundamentals**

In this first module, we develop a RESTful API with Node.js focused on the fundamentals of the technology, without external frameworks or libraries. We will learn about internal Node.js modules, especially HTTP and Streams, and about HTTP fundamentals like Requests, Responses, Headers, status codes, and the different types of parameters.
